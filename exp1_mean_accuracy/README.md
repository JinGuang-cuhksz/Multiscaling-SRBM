# Experiment 1 — Mean Approximation Accuracy

Compares the multi-scaling approximation to the skew-symmetric approximation on
the scaled second-coordinate mean `E[r^2 Z_2^{(r)}]`, benchmarked against the
exact stationary mean of Foddy (1984), available in closed form for this 2D
SRBM.

## SRBM setting

```
Gamma = I_2,
R     = [1 -beta; -alpha 1],
delta = (r, r^2),   mu = -R*delta,
```
with `alpha, beta in [0, 1]` and `r in (alpha, 1)` (so that both drift
components are negative). The exact value of `E[r^2 Z_2^{(r)}]` is computed
analytically; the multi-scaling prediction is `(1 + alpha^2)/(2(1 - alpha*beta))`
and the skew-symmetric prediction is `0.5`.

## Files

| file | role |
|---|---|
| `make_figure.m` | Computes the exact moments (via `../lib/rbm_moments.m`, the Foddy formulas) over a grid of `r`, then plots the relative error of both approximations and writes the paper figure. |

The shared analytical-moments routine `rbm_moments.m` and the legend helper
`legend_first_lines.m` live in `../lib/`.

## Reproduce

`make_figure.m` is self-contained (no simulation, no external data; runs in seconds).
It produces one PDF per `(alpha, beta)` pair. The figure in the paper has four
panels, generated by running the script four times with the two parameters at
the top of the file edited each time.

Mapping (note the in-script names are swapped relative to the paper):

| paper panel | paper `alpha` | paper `beta` | set `beta =` (line 12) | set `alpha_values =` (line 15) | output PDF |
|---|---|---|---|---|---|
| (a) | 0.25 | 0.5 | `0.25` | `[0.5]` | `rbm_relative_error_fixed_beta_0.25_0.5_linear.pdf` |
| (b) | 0.5  | 0.5 | `0.5`  | `[0.5]` | `rbm_relative_error_fixed_beta_0.5_0.5_linear.pdf` |
| (c) | 0.25 | 1   | `0.25` | `[1]`   | `rbm_relative_error_fixed_beta_0.25_1_linear.pdf` |
| (d) | 0.5  | 1   | `0.5`  | `[1]`   | `rbm_relative_error_fixed_beta_0.5_1_linear.pdf` |

```matlab
cd exp1_mean_accuracy
% edit `beta` (line 12) and `alpha_values` (line 15), then:
make_figure  % writes results/rbm_relative_error_fixed_beta_<a>_<b>_linear.pdf
```

Output PDFs are written to `exp1_mean_accuracy/results/`. The published copies
are in `../figures/`.
